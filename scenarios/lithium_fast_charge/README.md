- `evidence/`：证据表、论文登记、数据口径和UI映射
- `equipment/`：装置热点与典型曲线说明
- `bundle/`：网页读取的场景数据
- `figures/`：候选空间图
- `runs/`：后续 Agent 逐轮日志
- `validation/`：后续基线与消融结果
