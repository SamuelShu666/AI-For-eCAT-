- `20_literature_pdfs/`：20 篇文献状态清单及目前可下载的 PDF；详见其中的 `README.md` 与 `literature_download_index.csv`。

来源与访问状态以各自目录中的清单为准。未公开或被来源站点阻断的材料不以非授权副本替代。
