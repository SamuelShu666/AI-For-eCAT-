## 协作约定

1. 每位成员只在自己的 `members/member-*/` 目录内新增个人草稿和原始交付。
2. 进入整合版的代码按功能放入根目录的 `ecat/`、`demo_v2/`、`data/`，不要复制多份同名实现。
3. 合并前从 `main` 同步；不要用个人分支覆盖其他人的目录。
4. 原始 PDF、压缩包、聊天记录、API Key 和模型缓存不提交。
5. 任何结果数字必须注明数据版本（212 条槽电压或 180 条 Δη_RC）、运行次数和单位。
