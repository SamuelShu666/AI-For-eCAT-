eCAT 把文献、实验与决策写进同一张科研记忆图谱。在真实的 HER 合金槽电压数据上，Agent 只能看到组分，必须通过有预算的黑盒实验逐轮试错，用证据支撑每一个选择。

01

三层架构：决策与真值严格隔离

决策端读不到任何电压真值，只能通过预算受限的实验接口逐条获取，评测端独立打分。这样得到的性能曲线，反映的是 Agent 的真实发现能力。

LAYER 1 · 证据

文献证据库

  • 来源15 篇论文 PDF，按页切块
  • 检索TF-IDF 召回，保留 (文件, 页码)
  • 抽取LLM 抽取结论，必须引用真实块编号，否则丢弃
LAYER 2 · 决策

记忆闭环 Agent

  • 闭环检索 → 设计 → 校验 → 实验 → 诊断 → 记忆
  • 假设每轮提出可证伪假设，下一轮依据实验判定 支持 / 否定 / 存疑
  • 记忆文献 · 实验 · 决策三子图，共享元素节点，可导出 Neo4j
  • 引用每个候选必须引用文献结论 K 或历史实验 X
LAYER 3 · 实验

黑盒实验台

  • 输入候选编号（决策端只见组分）
  • 输出单个槽电压（越低越好）
  • 约束预算 40 次，禁止重复，全程留痕
真值表仅评测端可读
