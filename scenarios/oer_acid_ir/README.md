# PEM 酸性析氧低铱催化剂寻优

## 当前状态

- 场景 ID：`oer_acid_ir`
- 成熟度：`preview_ready`
- 候选数：114 条高质量、同行评审、Ir前驱体比例不超过10%的实验记录
- 来源论文：50篇
- 主指标：η10 @10 mA cm⁻²，越低越好
- 低铱指标：Ir前驱体比例，越低越好
- η10–Ir Pareto候选：4个
- 文献最低η10：165 mV

## 代表性候选

- 最高活性：RuIr NC，η10=165 mV，Ir=8%
- 超低Ir：IrO2@MTO-S，η10=240 mV，Ir=0.0173%
- 折中Pareto：Ir-based nanocages，η10=192 mV，Ir=0.461%

## 展示边界

这是公开文献数据的预览场景，不是eCAT本项目实验或Agent表现。不同论文的基底、负载、扫描速率和电解液条件不同，候选排名不能当成同一标准下的严格实验竞赛。

主动学习轨迹来自DASH公开批次记录。公开表内可计算的首轮批次最佳为206 mV，论文主文报告首轮最佳为209 mV；页面与图中应保留该口径说明。
