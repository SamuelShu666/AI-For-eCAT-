# eCAT 阶段性总结（2026-10-31）

## 一句话

面向碱性电解水抗反向电流 HER 催化剂，构建了"文献证据 + 规则校验 + LangGraph 决策闭环 + Neo4j 科研记忆"的智能筛选系统。

## 已完成

1. **文献知识库**：31 篇论文 → 2233 个 chunk，100% 带页码与 chunk_id；向量 + TF-IDF + RRF 混合检索，封装为 LangChain 工具。
2. **规则与先验**：8 条文献硬约束（全部回原文核验）+ 17 个元素级先验。
3. **Agent 闭环**：LangGraph 六节点（检索 → 设计 → 校验 → 实验 → 诊断 → 记忆），支持 memory / lit_only 两种模式，真值只对 execute 可见。
4. **科研记忆图谱**：Neo4j 中已建成 180 条 Material、31 篇 Paper、2233 条 Evidence、9 条 Claim；Agent 可按"共享元素"检索相似实验，并把每轮决策与结果写回图谱。
5. **对照实验**：随机 / 仅文献 / 文献+记忆，同一 180 条候选池、同一 20 次预算。

## 核心结果（20 次实验预算）

| 组别 | 最佳 Δη_RC | 最佳排名 | Top10 命中 | 首次命中 |
|---|---:|---:|---:|---:|
| 随机（n=20） | 7.7 mV | 8.2 | 2.3 | 6.5 轮 |
| 仅文献（n=3） | 8.1 mV（6.2–9.1） | 11.0 | 1.3 | 3.3 轮 |
| 文献+记忆（n=3） | **5.9 mV** | **2 / 180** | **7.0 / 18** | 5.0 轮 |

- 记忆组三次运行均为 5.9 mV，稳定收敛。
- 仅文献组三次为 6.2 / 9.1 / 9.1，依赖运气，波动明显。
- 全局最优为 C024（Co31Cr15Fe13Mo32Ni9，5.8 mV），与本系统结果相差 0.1 mV；只表述为"全局第 2"。

## 两个关键发现

1. **文献决定起点，记忆决定终点**：仅文献首次命中更快（3.3 vs 5.0 轮），但最终性能与 Top10 数量显著落后。
2. **先验盲区**：Top1 候选含 15% Cr，而系统在 220 次历史实验中从未测试任何含 Cr 组成——元素先验把 Cr 判为低活性。这说明知识先验既提升效率，也会形成系统性盲区，人类的价值在于质疑先验本身。

## 已知不足

- Claim 仅成功映射 9 条（4 条因页码/文本不匹配被跳过）。
