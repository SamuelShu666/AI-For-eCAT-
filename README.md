\# eCAT · 基于 AI Agent 的催化材料智能优化系统



面向碱性电解水制氢的抗反向电流 HER 催化剂智能筛选系统。

文献知识库（RAG）+ 规则校验 + LangGraph 决策闭环 + 实验反馈记忆。



> 参赛：浙江大学"启真问创·重器领航"智能过程装备创新创业大赛 · 题目二十一



\## 核心结果



在 180 条 Ni 基合金候选、20 次实验预算下：



| 组别 | 最佳 Δη\_RC | 最佳排名 | 20 次内 Top10 命中数 | 首次进入 Top10 |

|---|---|---|---|---|

| 随机搜索（n=20） | 7.7 mV | 8.2 | 2.3 | 6.5 轮 |

| 仅文献 Agent（n=6） | 7.0 mV | — | 3.0 | 2.0 轮 |

| 文献 + 实验记忆（n=5） | \*\*5.9 mV\*\* | \*\*2\*\* | \*\*7.4\*\* | 4.7 轮 |



\- 相比随机：最佳 Δη 低 23%，Top10 发现数约 3 倍

\- 相比仅文献：最佳 Δη 低 16%，Top10 发现数约 2.5 倍

\- 文献决定起点，记忆决定终点：仅文献首次命中更快，但记忆组最终收敛到第 2 名



\## 系统组成



1\. \*\*文献知识库\*\*：31 篇论文 → 2233 个 chunk，100% 带页码与 chunk\_id

2\. \*\*混合检索\*\*：向量 + TF-IDF + RRF 融合，封装为 LangChain 工具

3\. \*\*决策闭环\*\*：LangGraph 六节点（检索 → 设计 → 校验 → 实验 → 诊断 → 记忆）

4\. \*\*规则与先验\*\*：8 条文献硬约束 + 17 个元素级先验

5\. \*\*真值隔离\*\*：Δη\_RC 仅对 execute 节点可见，Agent 决策时不可见



\## 快速开始



&#x20;   pip install -r requirements.txt

&#x20;   python rebuild\_chunks\_v5.py     # 需自行在 pdf\_input/ 放入 PDF

&#x20;   python build\_index\_v5.py

&#x20;   python agent\_graph.py --mode memory --rounds 20



需要环境变量 `DEEPSEEK\_API\_KEY`，放在本地 `.env` 中，不要提交。



\## 数据说明



\- 候选池：180 条 Ni 基合金组成

\- 指标：Δη\_RC（反向电流应力前后 HER 过电位增量，mV，越低越好）

\- Top 10% 门槛：10.8 mV

\- 测试条件：1 M KOH、10 mA/cm²、三电极、Hg/HgO 校准至 RHE
