## 展示边界

这是公开文献实验记录的预览场景，不是eCAT本项目的材料实测或Agent运行结果。

不同论文的粉体合成、烧结温度、保温时间、压力、相纯度和电极界面并不完全一致。候选排序用于识别可检验方向，不能替代统一协议下的复测。

`dopant_count`只统计数据中显式列出的Li位、La位和Zr位掺杂元素，不等同原料成本、最终表面组成或器件制造成本。

当前最高电导来源论文 `10.1063/1.5019179` 尚未取得全文，仅保留DOI和公开元数据；其余代表性候选与主要活性悬崖来源已补入内部全文包。
