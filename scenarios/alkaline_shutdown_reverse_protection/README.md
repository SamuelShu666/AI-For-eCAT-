# 大型碱性电解槽启停反极保护调度：资料包

本目录为网页场景中心的内容底稿，目标是把可再生电力波动下的碱性水电解槽调度、启停安全与停机反向电流风险连起来。它提供可溯源的文献、公开数据入口、约束候选、参数先验、设备热点和验证计划；当前资料不能证明本项目已完成该场景的实测闭环。

场景元数据位于 `scenario_meta.json`。表内 `P01`、`R01`、`PR01`、`DS01` 是本资料包内的短编号；导入全项目Neo4j时应以 `alkaline_shutdown_reverse_protection` 作为命名空间拼接唯一键，避免与现有HER场景的编号冲突。

## 资料状态

- **数据**：找到公开的碱性电解实验数据和动态运行轨迹，但没有找到可公开下载、同时含工业级堆栈启停事件与反向电流/电极电位结果的 100–300 条实测候选池。见 `01_data_sources.csv`。不得将模拟、图表数字化或单电池数据标作大型堆栈实测结果。
- **文献**：`02_literature_registry.csv` 汇总 20 个优先来源，主题按 6 篇综述、8 篇系统/性能/调度、6 篇失效机理分配。PDF 均指向出版方或机构仓储；许可证和可复制文本状态需要按来源逐项复核后才可复制进公开仓库。
- **硬约束**：`03_hard_constraints.csv` 的数字是文献、标准试验方案或特定模型的边界。它们不是适用于所有设备的通用 PLC 设定值；正式控制必须以设备 OEM 手册、现场 HAZOP/SIL 和经验证的传感器阈值为准。
- **先验**：该场景是过程调度，不是材料配方筛选。因此 15 项先验使用运行参数和状态变量，替代“元素热力卡”。
- **图像**：建议使用 `equipment_and_conditions.md` 中 TU Clausthal 工业级测试平台实拍作为设备锚点，并遵守原页面署名/许可。可编辑版本应标为“设备示意/实拍”，不能混淆。

## 网页适配建议

1. 场景状态维持“资料预览/待闭环验证”。
2. 顶部 KPI 只显示数据集实际统计量与来源；现阶段不要显示“优化提升倍数”“冠军策略”或“实测闭环已验证”。
3. 3D 图谱可以先展示 `Paper–Evidence–OperatingState–Constraint–Policy–Run` 的文献静态子图，并明确其为文献知识图谱。
4. 回放和量化模块待取得真实事件级堆栈数据后再开启。

## 文件

- `01_data_sources.csv`：开放数据集、实验研究与适用边界。
- `02_literature_registry.csv`：20 个文献来源、PDF入口与场景用途。
- `03_hard_constraints.csv`：8 条候选安全/运行边界及页码定位。
- `04_domain_priors.csv`：15 个参数/状态先验卡短标签。
- `equipment_and_conditions.md`：设备图、四个交互热点、六项工况、代表性曲线。
- `05_validation_plan.md`：候选池组装、比较基准、真实闭环所需数据和时间预算。
