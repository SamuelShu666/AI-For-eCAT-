# 成员 B · 展示层与数据整合

成员 B 负责把文献解析、RAG 证据、逐轮实验反馈和科研记忆图谱整合成可检查的前端，同时保持新旧数据边界。

## 对应目录

- `../../demo_v2/`：当前 Ni-RC v2 展示。
- `../../demo/`：旧版 212 条槽电压展示，仅保留入口。
- `../../ecat/export_demo_v2.py`：统一数据导出器。
- `../../ecat/rag.py`：离线 TF-IDF + BM25 + RRF 重放适配器。
- `../../data/v2/`：文献 chunk 缓存与导出校验清单。
- `../../backend/`、`../../scripts/`：模型接入和辅助脚本。

## 当前展示口径

- 候选：180 条 Ni 基合金，17 种元素。
- 指标：Δη_RC，mV，越低越好。
- Top10%：18 条，阈值 10.8 mV。
- 文献库：21 篇 PDF、1490 个真实 chunk。
- 三次 Agent 运行：平均第 4.0 轮首次命中 Top10%，平均发现 7 个，最终最佳 5.9 mV、排名第 2。

## 页面重点

1. 20 轮 × 6 节点的实验回放，结果在实验节点前隐藏。
2. 原始运行证据与离线重放证据分栏，避免混淆检索来源。
3. 图谱固定“文献 / 共享元素 / 实验 / 决策”四个子图，支持本轮与累计视图、节点详情和追溯路径。
4. 页面内文献搜索可直接打开完整 chunk、出处和页码。
5. Agent 与随机搜索使用同一 180 条候选池和相同实验预算对照。

## 运行与重建

```bash
# 直接打开
start demo_v2/index.html

# 重新导出
python -m ecat.export_demo_v2
```

## 边界

旧版 212 条使用槽电压 V，v2 使用 Δη_RC mV，两者候选 ID 和数值口径不同，不混排、不混算。原始 Chroma / MiniLM 索引未交付，因此离线重放只用于可复现展示，不宣称复现原始向量排名。
